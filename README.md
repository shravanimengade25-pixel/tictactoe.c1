# Tic Tac Toe

A simple Tic Tac Toe game built using C language where two players can play against each other in the terminal.

## Features
- Two-player gameplay
- Win and draw detection
- Console-based interface
- Easy to understand logic

## Technologies Used
- C Language

## Project Purpose
This project was created to practice arrays, functions, loops, and game logic in C.

## How to Run
1. Compile the source code using a C compiler.
2. Run the executable file.
